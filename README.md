# Leaflens – Plant Disease Detection

A web application that detects plant diseases from leaf photos and
shares farming information for Maharashtra.

## Features
- Upload a leaf image and get the predicted disease
- Symptoms and treatment suggestions
- Maharashtra agriculture info (soils, crops, climate, regions)
- Organic supplements shop with a cart
- Dark mode

## Tech stack
- Frontend: React, Vite, React Router, CSS
- Backend: Node.js, Express (in progress)
- Model: MobileNetV2 (ONNX) with Transformers.js (in progress)

## How to run the frontend
```
cd plant-disease-app
npm install
npm run dev
```
